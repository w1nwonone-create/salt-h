# 분석 템플릿

Analyst Agent 가 사용하는 **검증된 분석 코드 템플릿**입니다.
Analyst 는 분석 계획·위치 연결 결과로 `PARAMS` 를 채운 코드를 생성해 `runs/<실행>/code/` 에 저장하고,
샌드박스(`tools/sandbox.py`)에서 실행합니다. 템플릿이 다루지 않는 질문은 LLM 이 같은 규약으로
코드를 새로 작성하며(오류 시 최대 3회 자가 수정), 동일한 샌드박스에서 실행됩니다.

규약
- 전역 `con`: 읽기 전용 DuckDB 연결 / `PARAMS`: dict
- 결과는 JSON 직렬화 가능한 `RESULT` dict 에 남깁니다.
- 수치는 모두 이 코드가 계산합니다. LLM 은 수치를 만들지 않습니다.
